## 它贵在哪：HKG.Pro 的线路

配置只是外壳，旺角真正值钱的是 HKG.Pro 的路由配置：

- 三网回程经香港 CTG 接入国内 CN2 GIA
- 电信去程走 CN2 GIA 直连香港 CTG
- 联通去程走 4837 + AS10099
- 移动去程走 CMI 直连

测试 IP 是 103.117.100.199。第三方测评给出的数据不完全一致：有 2026 年的测速文记录大陆多地平均延迟在 49ms 上下，也有整理资料说三网 Ping 平均约 43ms（电信、联通 42ms 左右，移动 46ms）。不同时间、不同宿主机平台的结果本来就会有浮动，把 40–50ms 当成参考区间比较靠谱，别把某个具体数字当承诺。

150Mbps 对个人建站、远程开发、轻量跨境业务是够的。它的短板也很清楚：1 核 1G 20G，跑偏重的应用会紧张，配置是"够用"级别，不是性能款。

## 和 Tier 1 别搞混

DMIT 香港还有一条 Tier 1 线（型号前缀 HKG.AS3.T1），价格更便宜，年付 $36.9 起。但它走的是国际 BGP 线路，对中国大陆没有专项优化，接入的是 RETN 这类国际运营商。对有大陆访客的业务来说，这不是省钱，是选错了产品——电信用户买到 T1，延迟有可能比买美国机房还高。

判断方法很简单：你的用户主要在大陆、对延迟敏感，就只能在 Premium 这一档里挑；你只是需要一个香港 IP 做落地、国际中转或者面向海外用户，T1 的性价比反而更高，流量和带宽都给得很足。

## 下单前值得知道的几个细节

**付款方式**：支付宝、微信、PayPal、信用卡都能用，国内用户下单没有障碍。

**IP 这件事最容易被忽略**：月付周期分配的 IP，商家不保证全球可用。下单时可以选择多花 $1 买 Guarantee+，如果分配到的 IP 不可用，事后想换要付 $5。做流媒体解锁或者对外业务的人，这 $1 建议别省。

**流量用尽不是停机**：T1 系列超额后进入限速模式，WEE 限速 50Mbps，其他档位按配置给到更高的保底带宽，服务继续可用。这一点比"流量用完直接暂停"的产品体验好很多。

**库存节奏**：香港 Premium 一直是 DMIT 最紧俏的货，补一批少一批，公开的补货通告也不规律。如果你确定要买 Pro，看到库存别反复比较太久。

## 几个常被问到的点

**旺角是机房名吗？** 不是。它是限量款的产品名，机房在香港，测试 IP 归属香港且走 DMIT 自己的 AS906。名字里的香港地名只是营销命名，不代表独立的物理机房。

**续费还是 $149.9 吗？** 这类年付限量款的实际续费价格以账单页显示为准。本文只说明它当年的发售价格，不做长期续费承诺。

**第一台 VPS 值得为了旺角去二手市场加价吗？** 大概率不值得。旺角的吸引力集中在"价格 + CN2 GIA 线路"这个组合上，一旦二手溢价把价格抬到接近常规款，溢价买来的就只剩稀缺性。同样的钱拿去直购 HKG.Pro 常规款，链路、售后、续费都更干净。

**Tier 1 和 Pro 差多少？** 差在路由。Pro 三网都有针对大陆的优化，Tier 1 没有。你在国内用电信网络访问 T1，延迟高于美国节点是可能出现的情况，这不是故障，是线路定位决定的。
